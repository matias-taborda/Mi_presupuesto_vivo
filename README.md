# 💰 Control de Finanzas Personales en Python
## 📌 Descripción
Proyecto desarrollado en Python utilizando Jupyter Notebook, orientado al control y análisis de finanzas personales.
Permite registrar ingresos, gastos y aplicar reglas de ahorro automáticas para facilitar la toma de decisiones financieras.
El objetivo principal es ofrecer una herramienta simple, clara y reutilizable, pensada para el uso personal o como base para futuros desarrollos financieros.
## 🎯 Objetivos del proyecto
Registrar ingresos mensuales  
Clasificar gastos  
Calcular capacidad de ahorro  
Aplicar porcentajes de ahorro predefinidos  
Evaluar si los objetivos financieros son alcanzables  
## 🧠 Lógica del sistema
El sistema trabaja a partir de:  
Ingreso del monto mensual  
Cálculo automático de:  
Ahorro de meta (15%)  
Colchón financiero (10%)  
Evaluación del saldo disponible luego de gastos y ahorro  
Los porcentajes pueden adaptarse según la situación financiera del usuario.
